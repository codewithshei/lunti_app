NOTES

  • Status updates are real-time. Every change writes the document once; the mobile app and the Admin Studio both follow it with a snapshot listener, so neither has to reload.
  • Fulfilment advances one step at a time. pending → approved → packed → shipped → completed. Skipping or reversing a step is rejected.
  • Every change is audited. Each transition appends a statusHistory entry recording the new status, the timestamp and the acting admin.
  • Cancellation is available from any non-final status and returns each item's quantity to the catalog exactly once.
  • Completion settles payment automatically. A delivered cash-on-delivery order is marked Paid (COD); GCash and card orders were already settled at checkout.
